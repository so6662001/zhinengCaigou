# 钢采智配 · 自动化采购配货与比价系统 —— 系统设计方案

作者视角:钢铁现货批发企业采购员(20 年工龄)
适用对象:年采购量 20 万吨以上、多仓库 / 多客户 / 多品规的钢贸企业

---

## 1. 业务背景与痛点

钢贸采购每天的真实工作流:

```
销售报需求(微信/电话) → 采购手抄 Excel → 打电话问 5~8 家 → 记在本子上
→ 凭经验选「老关系」→ 手工拆单 → 微信/电话下单 → 等到货 → 事后发现磅差/质保书缺
```

| 痛点 | 后果 | 量化(本公司上线前) |
| --- | --- | --- |
| 需求汇总靠人 | 漏单、错规格、错定尺 | 月均 3~5 单差错 |
| 询价覆盖不足 | 平均只问 2.1 家 | 采购价高于市场 +8~15 元/吨 |
| 表面报价不可比 | 理计 / 磅计、运费、账期没折算 | 「捡便宜」反而多付 50+ 元/吨 |
| 配货凭经验 | 多品规配齐时高价配齐 | 不可量化的隐性损失 |
| 耗时 | 单张需求 3.5 小时 | 2 名采购全职 |
| 风控滞后 | 磅差、质保书缺失事后才发现 | 索赔回收率 &lt; 40% |
| 知识流失 | 老采购离职带走关系与价格记忆 | 新人上手 3~6 个月 |

## 2. 系统目标

| 指标 | 传统手工 | 系统目标 |
| --- | --- | --- |
| 单张需求配货耗时 | 3.5 小时 | ≤ 5 分钟(采购员仅确认) |
| 每单有效报价数 | 2.1 家 | ≥ 5 家,比价覆盖率 100% |
| 采购均价 vs 市场均价 | +8 元/吨 | ≤ −20 元/吨 |
| 到货准时率 | 92% | ≥ 98% |
| 磅差索赔回收率 | &lt; 40% | 100%(自动发函) |
| 新采购员上手 | 3~6 个月 | 1 天 |

## 4. 核心模块设计

### 4.1 需求池与规格标准化

- 来源:ERP 销售订单、销售端小程序录入、安全库存补货预警(按仓库 × 规格的动销天数自动生成)。
- 标准化字段:品名 / 材质 / 规格(直径、厚×宽×长)/ 定尺 / 钢厂偏好 / 计重方式(允许理计?)/ 到货地(经纬度)/ 要求交期 / 价格上限(销售合同价 − 最低毛利)/ 允许分批 / 允许替代材质。
- 自动合并:同到货地、同交期窗口的多单合并为一次询价与配货,提升谈判量级。

### 4.2 到厂价归一化引擎(比价的核心)

所有报价折算为统一口径 **「磅计 · 现款 · 到工地 · 含 13% 税 · 元/吨」**:

```
到厂价 = 原始报价 ÷ (1 − 理计负差率)          ← 理计资源折算为磅计等价(负差率取该钢厂/供应商画像的近 90 天实测中位数)
       + 运费(距离 × 车型费率,实时取物流平台运价;直发按钢厂到工地,库提按库到工地)
       + 装卸 / 短驳 / 二次倒运
       + 账期资金成本(年化资金成本 × 账期天数 ÷ 365;承兑按贴息率)
       + 磅差风险溢价(该供应商历史磅差超阈值概率 × 平均超限幅度 × 价格)
       + 新供应商 / 非协议风险溢价(固定 12 元/吨,可配置)
       + 质保书 / 合规缺失惩罚(缺失直接剔除)
```

同时输出**成本结构分解**(堆叠条)与**报价原文回溯**(企微文本 / 小程序 JSON / 录音片段),保证每个数字可审计。

### 4.3 报价采集与结构化

| 渠道 | 采集方式 | 结构化方法 |
| --- | --- | --- |
| 企微群 / 私聊 | 企微 API 拉取 | NLP 抽取品名 / 规格 / 仓库 / 价格 / 计重 / 付款 / 可供量 / 交期,置信度 &lt; 95% 转人工复核 |
| 供应商小程序 | 结构化表单 | 直接入库 |
| 钢厂 / 平台 API | 沙钢云、找钢网等 | 直接入库 |
| 电话 | 录音 ASR | 同 NLP 抽取,保留音频片段可回放 |
| 邮件 / Excel | 解析附件 | 模板匹配 |

自动催报:截止前 60 / 15 分钟两次催报;连续 3 次不回复自动下调「响应速度」评分。

### 4.4 配货约束求解引擎

建模为混合整数线性规划(MILP):

- **决策变量** \(x_{ij}\):需求行 \(i\) 从资源 \(j\) 采购的吨位;\(y_j \in \{0,1\}\):是否启用资源 \(j\)。
- **目标函数**(多目标加权,权重采购员可调):

  \[
  \min \; w_1 \sum_{ij} c_{ij} x_{ij} \;+\; w_2 \sum_{ij} \text{delay}_{ij} x_{ij} \;-\; w_3 \sum_{ij} \text{credit}_j x_{ij} \;-\; w_4 \sum_{j \in \text{自有库存}} \text{age}_j x_{ij}
  \]

  其中 \(c_{ij}\) 为归一化到厂价,delay 为超出交期的天数,credit 为供应商评分,age 为库龄。
- **硬约束**:
  - 需求满足:\(\sum_j x_{ij} = D_i\)(允许分批时 ≥ 最小交付量)
  - 资源可供:\(\sum_i x_{ij} \le S_j \cdot y_j\)
  - 单一供应商占比 ≤ 35%
  - 价格上限:\(c_{ij} \le P^{max}_i\)
  - 交期硬约束(可切换为软约束加惩罚)
  - 黑名单 / 非协议 / 质保书缺失资源排除
  - 起订量、整车约束(33 吨/车取整)
- **输出**:方案 A(成本最优)/ B(时效优先)/ C(均衡分散);每个方案给出配齐率、供应商分布、直发比例、信用加权分;缺口自动生成替代方案(接受延期 / 高价现货 / 通知销售分批)。
- **可解释性**:每条配货决策附「为什么」(价差、负差折算、短驳成本、贴息等)与求解日志。
- **重算触发**:行情更新、报价到达、资源变动、策略调整时增量重算(秒级)。

### 4.5 供应商画像与评分

```
综合分 = 价格竞争力 30 + 履约准时 25 + 质量/磅差 20 + 响应速度 10 + 资金条件 10 + 合规 5
```

- 价格竞争力:近 90 天报价与成交价相对市场基准的偏差,按规格分层。
- 履约:准时率、可供量兑现率、封盘频率。
- 磅差:平均磅差、超阈值次数、理计负差稳定性(标准差)。
- 响应:报价中位响应时间、有效报价率、议价接受率。
- 资金:账期、承兑贴息、预付要求。
- 合规:质保书齐全率、发票及时率、黑名单事件。
- 画像洞察:按规格 / 星期 / 调价周期的价格规律,用于询价时机与锁量策略。

### 4.6 行情与调价预测

- 数据:Mysteel / 找钢 / 钢银 现货价、上期所 rb / hc 盘面与基差、社会库存、日成交量、钢厂周产量、钢坯价、宏观日历。
- 钢厂调价预测:基于历史调价与盘面涨跌、库存、成本的关系建模,给出概率与幅度(如「沙钢中旬 +30,概率 78%」)。
- **买入时机指数(0~100)**:盘面动能、钢厂挺价、库存去化、成交放量、基差、宏观、季节性加权。
- 联动:指数 &gt; 75 触发「涨价预警模式」,配货引擎时效权重 +5%,优先即时可提资源,并提示销售缩短报价有效期。

### 4.7 风控与审批

| 阶段 | 规则 | 动作 |
| --- | --- | --- |
| 下单前 | 单笔 / 单日授权额度 | 超限进入审批流(企微推送) |
| 下单前 | 到厂价偏离基准 &gt; ±30 元 | 需填写说明 + 审批 |
| 下单前 | 黑名单 / 质保书缺失 / 非协议 | 自动排除或标记核验 |
| 到货 | 磅单 OCR 比对合同吨位 | 磅差超阈值自动生成索赔单、扣款、扣信用分 |
| 到货 | 质保书号与炉批号匹配 | 不匹配拦截入库 |
| 事后 | 采购复盘 | 自动生成周报:节省、偏差、供应商表现 |

### 4.8 执行跟踪

合同待签 → 审批中 → 待提货/发运 → 在途(GPS)→ 到货核验 → 结算/归档 的看板;所有节点由系统自动推进,采购员只处理红色异常卡片。

### 4.9 资源库存(自有 + 在途)

- **可用量 = 在库 + 在途 − 已锁定**,是配货引擎的第一资源池;在途按预计到货时间参与配货,延迟自动重算。
- 按仓库 × 品名 × 规格 × 钢厂维度维护库龄、成本价、当日市价、浮盈亏、日均销量、可售天数。
- 呆滞判定(库龄 &gt; 90 天或可售 &gt; 45 天)自动给出调拨 / 促销建议;浮亏规格在配货中对同规格外采加价 +20 元等价,优先消化自有。

### 4.10 安全库存自动运算引擎

每日 05:30 对全部「仓库 × 规格」自动运算,输出安全库存(SS)、补货点(ROP)、目标库存与补货量,并直接生成补库需求进入需求池。

**模型(需求与提前期双波动)**

```
SS      = Z × √( LT × σd² + d̄² × σLT² )
ROP     = d̄ × LT + SS
目标库存 = ROP + Q
补货量   = 目标库存 − 可用量(在库 + 在途 − 锁定)

Q       = max( EOQ, 覆盖天数 × d̄ ) → 整车向上取整(建材 33t / 板卷 25t),受单规格资金上限约束
EOQ     = √( 2 × D × S / H )     D 年需求量,S 订货固定成本,H 单位持有成本(资金年化 + 仓储)
```

**输入与处理**

| 项 | 来源 | 处理 |
| --- | --- | --- |
| d̄、σd | ERP 出库流水近 8 周 | 近 2 周权重 ×2;剔除 &gt; 3σ 单日脉冲;叠加季节因子与在手订单 |
| LT、σLT | 供应商画像实测提前期 | 按主供应商 → 仓库路线取中位数与标准差 |
| Z(服务水平) | ABC-XYZ 矩阵 | A-X 99% / A-Y 97.5% / B-X 97.5% / B-Y 95% / C-X 90% / C-Y、C-Z 按单采购(SS = 0) |
| 行情修正 | 买入时机指数 | 指数 &gt; 75 覆盖天数 +3;&lt; 40 覆盖天数 −2 |
| 资金 / 仓储成本 | 财务 | 年化 7.2% + 0.8 元/吨/天 |

**判定与动作**

| 状态 | 条件 | 系统动作 |
| --- | --- | --- |
| 需补货 | 可用 ≤ ROP | 生成 RPL 补库需求;≤ 100t 自动进需求池,&gt; 100t 采购确认;可与同地销售需求合并询价或拼车 |
| 观察 | 可用 ≤ ROP 但在途到货后 &gt; ROP | 暂不补,次日复算 |
| 健康 | ROP &lt; 可用 ≤ 目标 | 无 |
| 过高 | 可用 &gt; 目标 | 建议下调 / 调拨 / 促销;涨价预期下可「行情豁免」 |
| 参数变化 | 画像 LT 或销量分布变化 | 自动重算 SS,记录变化原因 |

**闭环**:05:30 运算 → RPL 进需求池 → 06:00 配货引擎统一求解 → 到货入库 → 次日复算。支持近 90 天回测(缺货率、库存资金对比)。

### 4.11 销售需求池

- 唯一入口:ERP 销售订单、销售端小程序(自由文本)、安全库存补库、长协排产。
- NLP 规格标准化:品名 / 材质(缺省按客户历史)/ 规格 / 吨位 / 到货地 / 交期(自然语言 → 工作日)/ 计重方式 / 替代允许;置信 &lt; 90% 自动 @销售确认。
- 自动合并:同到货地 + 同交期窗口 + 同品种 → 合并询价、拼车;每单带价格上限(合同价 − 最低毛利),从源头保护毛利。

### 4.12 配货规则 / 权重

- 策略模板按品种 × 区域 × 客户等级生效;包含目标权重、硬约束、加减分(折算为元/吨等价)、到厂价折算参数。
- 自动触发:买入时机指数、钢厂调价预测、供应商集中度、磅差事件、RPL 阈值等触发模板切换或参数调整。
- 任何修改先用近 30 天需求回放做回测(成本 / 准时率 / HHI 对比),再提交采购总监审批生效;版本全留痕。

### 4.13 风控与审批流

- 下单前自动校验:单笔 / 单日额度、价格偏离、异常低价、毛利穿底、供应商资质、黑名单及关联方(同法人 / 同收款账户)、集中度、预付款、资金占用。
- 分级审批:≤ 50 万自动下达;50–200 万采购经理;&gt; 200 万总经理;价格偏离与新供应商并行会签;超时自动提醒并升级。
- 审批卡片附引擎「审批要点」(价差、信用、占比、唯一超限项),支持「拆单后自动通过」。
- 到货与结算:磅差 / 质保书不匹配挂起付款并索赔;合同 – 磅单 – 发票三单匹配。

### 4.14 管材 / 型材 / 板材:几千个 SKU 的治理方式

钢贸企业以管材、型材、板材为主时,SKU 数量通常在 3,000~10,000(管材 外径 × 壁厚 × 材质 × 长度;型材 型号 × 材质 × 长度;板材 厚 × 宽 × 长 × 材质)。逐 SKU 做安全库存、比价、配货在人工上不可行,系统采用「品类 → 规格族 → SKU」三层模型:

| 层 | 定义 | 用途 |
| --- | --- | --- |
| L1 品类(3) | 管 / 型 / 板 | 总量目标、资金上限、季节因子、行情修正 |
| L2 规格族(~140) | 板材:材质 × 厚度(大板可切小板);管材:品种 × 材质 × 外径段;型材:品种 × 材质(9m / 12m 互替) | 族级安全库存(合并方差)、合并补货凑整车、族整单比价、替代配货 |
| L3 SKU(~4,860) | 具体规格 | 仅 A/B 类(约 18% SKU、82% 销量)独立 SS / ROP;C 类按单采购 + 族内替代 + 拼车 |

**安全库存**:族级 \(SS_{族} = Z\sqrt{\sum \sigma_i^2 + \sum\sum \text{Cov}}\) 小于逐 SKU 求和;板材凭切割替代、型材凭长度互替形成真实共享,管材主要用于拼车与资金约束。实测安全库存总量约 −22%,服务水平不降。

**比价**:采用行业惯例的 **基价 + 加价表** 模型(见 4.15),询价按规格族发出,供应商只改基价;系统展开逐规格到厂价后同时计算「单一供应商整单价」与「拆单最优」(每多一家供应商加 8 元/吨 对账装卸成本),给出推荐。

**配货**:品类规则内置 —— 板材切割 / 开平替代与 25t 板卷装车;型材 12m → 9m 切割、车长 ≤ 13m;管材外径不可替代、壁厚可向上替代需确认、按体积限载、同供应商多规格拼车;一单多规格允许拆 ≤ 3 家。

### 4.15 供应商价格库(Excel 导入 / API 取价)

**价格模型**

```
SKU 价格 = 基价(品种 × 材质 × 供应商 × 仓库)
         + 规格加价(外径×壁厚 / 型号 / 厚度 加价表,行业通用或供应商自定义)
         + 长度 / 定尺 / 加工加价(12m、定尺、开平、剪切、镀锌层)
         + 材质加价(Q355B +150 等)
→ 进入到厂价归一化(运费 / 账期 / 磅差 / 信用)
```

供应商三种报价方式:① 只报基价、沿用通用加价表;② 基价 + 自定义加价表;③ 上传全规格 Excel,系统反推基价与加价表并校验一致性。几十个基价即可展开全部 SKU 价格。

**Excel 导入向导**:上传(拖拽 / 邮箱自动收件 / 微信截图 OCR)→ 智能列映射(按供应商历史模板自动匹配,置信度标注)→ 校验(规格标准化:寸 / DN / mm 换算、缺省材质与长度;价格异常:偏离上次 &gt; 5% 提示核对;新 SKU 自动建档)→ 差异预览(上调 / 下调 / 持平 / 新增 / 失效)→ 入库并刷新比价矩阵。映射模板保存后,同格式邮件全自动入库,仅异常行提醒。

**API 取价**:找钢网、钢银、欧冶云商、Mysteel、钢厂云商(沙钢 / 马钢 / 鞍钢 / 中天等)、供应商小程序;按频率自动拉取,限流自动降频,Token 失效自动切 RPA 兜底。

**有效期管理**:价格超过有效期灰显、不参与自动配货,自动催报;连续过期下调供应商「响应」评分。

### 4.16 接口中心

四种接入方式(API / RPA 抓取 / 邮件 Excel 解析 / 企微·电话 NLP)统一落到标准化层(品类 → 规格族 → SKU 标准编码、单位与计重换算、供应商别名映射、去重),再进入价格库 / 资源池 / 库存 / 运价 / 行情 / 单据等数据资产。每条数据带来源、原文、时间、置信度四要素;数据到达通过事件触发引擎(调价公告 → 折算规则与配货重算;价格入库 → 比价刷新;WMS 出入库 → 可用量与安全库存复算;GPS 延迟 → 在途重算;磅单 OCR → 三单匹配与索赔)。

## 6. 落地路径

1. **阶段一:比价先行** —— 接入企微 + 小程序报价采集与到厂价归一化,采购员立刻感受到「表面低价陷阱」被揭穿,建立信任。
2. **阶段二:配货引擎** —— 接入 ERP 需求与库存,先以「建议模式」并行运行,人工确认;两周后切换「自动模式 + 异常人工」。
3. **阶段三:画像与行情** —— 积累 3 个月数据后开放供应商评分驱动配货、调价预测与涨价预警模式。
4. **阶段四:全流程执行** —— 电子签、物流、磅单 OCR、自动索赔、财务联动。

## 7. 为什么采购员会认为「必须用」

- **算得比人细**:到厂价把磅计 / 理计、运费、账期、磅差都折进去,人脑做不到每单都算。
- **看得比人多**:每单 5 家以上报价、3,000+ 条资源、60 天行情、86 家画像,同时进入决策。
- **快得离谱**:3.5 小时变 4 分钟,采购员从「打电话的人」变成「做决策的人」。
- **说得清楚**:每一条配货、每一个价格都有出处和理由,老板追问时一键导出。
- **不背锅**:授权、价格偏离、黑名单前置拦截;磅差自动索赔;复盘自动生成。
- **走不了的资产**:关系、价格记忆、供应商脾气全部沉淀为画像,新人一天上手。
