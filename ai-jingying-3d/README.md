# 钢贸AI经营系统 · 3D 动态全景

用一张会动的 3D 沙盘,让客户看懂「一张订单」怎样在 AI销售、AI采购、AI仓库、AI提货宝、AI出纳、AI经营 六个岗位之间流转,以及每个岗位带来的价值。用于销讲大屏和会后 1 对 1 讲解。

## 能看到什么

- **3D 沙盘**:客户、供应商和六个 AI 岗位各是一栋建筑;订单、货物、资金在地面上流动,各岗位的数据汇到中间的 AI经营。
- **导览步骤条**:全景 → 六个岗位 → 总结,可手动翻页,也可「自动导览」。
- **岗位详情**:点任意建筑,右侧显示「以前这样干 / 现在 AI 这样干 / 带来的价值 / 核心能力 / 上线提醒」。
- **传统做法 / AI经营 对比**:右上角一键切换,传统做法下流动变慢、数据不再汇给老板,每个岗位亮出痛点。
- **算算你家的账**:填入客户自己的采购量、库存等,按可调的假设估算一年的收益。
- **上线须知**:上线前、上线中、上线后三个阶段的注意事项,以及各岗位的上线提醒。

## 怎么运行

需要 Node.js 20 以上。

```bash
npm install
npm run dev            # 本地预览,浏览器打开终端里显示的地址
npm run build          # 生成可部署到网站的 dist/
npm run build:offline  # 生成单个文件 dist-offline/index.html,断网时双击即可演示
```

## 怎么改内容

全部文案集中在 `src/content.js`,改完保存即可,不用动 3D 代码:

| 想改什么 | 改哪里 |
| --- | --- |
| 各岗位的痛点、做法、价值、能力、上线提醒 | `NODES` |
| 导览每一步底部的讲解词 | `STEPS` |
| 总结页的几条价值 | `SUMMARY` |
| 「算算你家的账」的默认值和假设 | `CALCULATOR` |
| 上线注意事项 | `GOLIVE` |

建筑位置在 `src/scene/nodes.js` 的 `LAYOUT`,流动路线在 `src/scene/flows.js` 的 `SEGMENTS`。

## 演示小技巧

- 键盘 `←` `→`(或翻页笔的上一页 / 下一页)切换步骤,空格开始或暂停自动导览,`Esc` 回到全景。
- 网址后加参数:`?autoplay=1&loop=1` 展台循环播放;`?step=purchase` 直接打开某一步;`?mode=old` 从传统做法开始。

## 内容说明

AI采购 的能力来自已确认的产品功能;其余五个岗位的文案、上线须知和测算的默认假设是按钢贸行业通常做法写的初稿,正式对外使用前请按真实产品功能和客户数据核对修改。
