# 钢采智配 SteelBuy —— 钢铁现货批发 · 自动化采购配货与比价系统

> 面向钢贸企业采购部门的高保真原型(纯静态 HTML/CSS/JS,无需构建,双击 `index.html` 即可浏览)。
> 设计目标:让采购员只做「确认」和「处理异常」,把询价、比价、配货、下单、跟踪、核验、索赔全部交给系统。

## 核心理念(来自 20 年一线采购经验)

1. **表面报价不可比,只有「到厂价」可比。** 磅计 / 理计、运费、装卸、账期、磅差风险、质保书缺失……任何一项没折算,比价就是在赌运气。
2. **配货不是「找最便宜的一家」,是「多品规、多来源、多约束下的组合最优」。** 配齐率、交期、单一供应商占比、自有库存消化,都得同时算。
3. **行情决定节奏。** 钢厂调价前一天锁量,与调价后一天下单,一吨差 30 元;系统必须把行情判断内嵌到配货策略里。
4. **老采购的人脉和记忆要变成公司的数据资产。** 供应商画像让新人一天上手,让引擎替代「拍脑袋」。
5. **风控要前置。** 授权额度、价格偏离、黑名单在下单前拦截;磅差、质保书在到货时自动比对;索赔自动发函。
